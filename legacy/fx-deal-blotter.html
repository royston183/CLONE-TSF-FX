Notes
  1. Use the date format DD-MM-YYYY throughout this standalone blotter.
  2. Deal Creation: after entering data, select one or more rows and choose Create Transaction. A transaction number is assigned and the row becomes read-only.
  3. Errors & Deletion: draft/error rows can be deleted and re-entered. Created transactions can be reversed through the existing reversal flow.
  4. Release to MO: after creation, select one or two Created transactions and release them to Mid-Office. Released rows remain read-only.
  5. For NDF / DNDF transactions, settlement handling follows the USD-oriented logic represented in the supplied program.
