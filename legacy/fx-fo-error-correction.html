Note: Each row here is one FX financial transaction (Transaction No), not a Master Contract or a Deal in the abstract — a Deal ID commonly has two transaction rows (e.g. one booked at the OGA/Singapore leg and one at the DMCC/Dubai leg) that together form the offsetting pair. A transaction lands here as Correction Required when Mid-Office sends it back — read MO Remark for their reason. Use FX Error Correction to update the flagged fields (Business Partner, rates, amounts, dates, Business Area, etc. — mirroring the SAP "Old Details / New Details" popup) and resubmit, or Reverse if the transaction should be cancelled outright. Only Correction Required rows can be selected; this queue is scoped to Display Type: FX — Options-type transactions are handled on the separate Options queue and are not shown here.
Deal ID – the Front Office booking identifier that links two offsetting transactions. Transaction No – the individual SAP TRM financial transaction (rfha) this screen corrects. Master Contract – the underlying trade contract this transaction's FX exposure is booked against.
