Note: This list only ever shows Master Contracts booked under a Short Straddle FX Model (ZSS = 'X' on the FX Model master) and whose shipment window has not yet closed relative to As of Date (WHERE zship_end > p_date) — both match the ABAP selection logic exactly, they're just applied live as filters instead of a separate selection screen. Click a MC Ref No to view the full Master Contract detail popup (equivalent to function module ZSGTSFFM_MC_DETAILS). Click the Uti-Deal ID Amt(USD) value to drill into the Deal ID / FX leg breakdown for that contract (equivalent to SUBMIT ZSGTSF_RDEAL_ID_DETAIL). Click anywhere else on a row to select it for the toolbar actions above — only one row can be selected at a time, matching the ALV single-row selection used by the EDIT_MC and DEAL custom functions in the original transaction.
